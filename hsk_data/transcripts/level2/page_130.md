When the object is a personal pronoun, the complement of frequency should be put after the object. For example:

| Subject | Predicate | | | |
|---|---|---|---|---|
| | V | 过 | O | Num+次 |
| 我们 | 找 | 过 | 他 | 三次。 |
| 他们 | 看 | 过 | 我 | 一次。 |
| 老师 | 叫 | 过 | 我 | 两次。 |
