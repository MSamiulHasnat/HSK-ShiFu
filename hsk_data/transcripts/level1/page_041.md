### 2 认识独体字 Single-Component Characters

(1) "七"，表示数量 "7"。
"七" means "seven".

[illustration: stroke evolution diagram 十 → 十 → 冫 → 七, labeled qī, with character grid showing stroke order 一 七]

(2) "儿"，本义是小孩。现在多指儿子。
"儿" originally meant "kid", but now it usually means "son".

[illustration: stroke evolution diagram (pictograph of child) → 兒-like form → 儿, labeled ér, with character grid showing stroke order 丿 儿]

(3) "几"，本义是小矮桌。
"几" originally referred to a small and low table.

[illustration: stroke evolution diagram 几-pictograph → 几 → 几, labeled jǐ, with character grid showing stroke order 丿 几]
