**1** 双人活动 Pair Work

两人一组对话，用"一……也/都＋不/没……"互相反驳。例如：

Work in pairs to make dialogues, contradicting each other using "一……也/都＋不/没……". For example:

例如：A：我觉得今天很冷。

B：我觉得一点儿也不冷。我想吃一个苹果。

A：我一个苹果也不想吃。

**2** 小组活动 Group Work

3~4人一组，讨论打算去哪儿旅游，怎么去，旅游以前要准备什么。每组请一位同学记录，并向全班报告。

Work in groups of 3-4. Discuss where you are planning to go traveling, how you will go, and what should be prepared before the trip. Ask one member to take notes and report the results to the whole class.
