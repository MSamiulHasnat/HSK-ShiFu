**1** 朗读下列短语和句子 (Dúlǎng xiàliè duǎnyǔ hé jùzi) Read the following phrases and sentences aloud. 🔊 03-5

① 记得 (jìde)：不记得/记得带钱/你还记得我吗/我记得你已经有两条这样的裤子了。
bú jìde / jìde dài qián / nǐ hái jìde wǒ ma / wǒ jìde nǐ yǐjīng yǒu liǎng tiáo zhèyàng de kùzi le.

② 新鲜 (xīnxiān)：很新鲜/不新鲜/新鲜的鱼/这些水果真新鲜。
hěn xīnxiān / bù xīnxiān / xīnxiān de yú / zhèxiē shuǐguǒ zhēn xīnxiān.

③ 放 (fàng)：放在桌子上/放在外边/放在哪儿/桌子上放着很多饮料。
fàng zài zhuōzi shàng / fàng zài wàibian / fàng zài nǎr / zhuōzi shàng fàngzhe hěn duō yǐnliào.

④ 只 (zhǐ)：只学汉语/只会说，不会写/这儿只卖书，不卖水/今天晚上只吃水果不吃饭。
zhǐ xué Hànyǔ / zhǐ huì shuō, bú huì xiě / zhèr zhǐ mài shū, bú mài shuǐ / jīntiān wǎnshang zhǐ chī shuǐguǒ bù chī fàn.

⑤ 条 (tiáo)：一条鱼/一条裤子/一条路/你觉得这条裤子怎么样？
yì tiáo yú / yì tiáo kùzi / yì tiáo lù / nǐ juéde zhè tiáo kùzi zěnmeyàng?
