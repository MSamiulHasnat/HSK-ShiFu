表示通过动作使某确定事物发生关系上的转移，可以用"A把B+V+给+sb."例如：

If an action has changed the owner or user of a definite object, the structure "A把B + V + 给 + sb." is used. For example:

（5）我把鲜花送给老师了。

（6）我朋友把书借给我了。

（7）弟弟没把钱还给哥哥。

（8）你帮我把这本书带给小刚。
