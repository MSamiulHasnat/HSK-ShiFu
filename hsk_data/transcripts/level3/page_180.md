### 1 朗读下列短语和句子 Read the following phrases and sentences aloud. [audio icon] 19-5

① 短：很短/短头发/短一点儿/她小时候喜欢短头发。
Duǎn: hěn duǎn / duǎn tóufa / duǎn yìdiǎnr / tā xiǎoshíhou xǐhuan duǎn tóufa.

② 蓝：蓝色/蓝衬衫/天很蓝/他今天穿蓝西服，看上去像40多岁。
Lán: lánsè / lán chènshān / tiān hěn lán / tā jīntiān chuān lán xīfú, kàn shàngqù xiàng sìshí duō suì.

③ 过：过生日/过节/过周末/她刚过完一岁生日。
Guò: guò shēngrì / guò jié / guò zhōumò / tā gāng guòwán yí suì shēngrì.

④ 船：一条船/坐船/船上/我坐在船上一边看（黄河），一边照相。
Chuán: yì tiáo chuán / zuò chuán / chuán shang / wǒ zuò zài chuán shang yìbiān kàn (Huánghé), yìbiān zhàoxiàng.

⑤ 经过：经过超市/经过图书馆/经过一条河/一路上经过了很多地方。
Jīngguò: jīngguò chāoshì / jīngguò túshūguǎn / jīngguò yì tiáo hé / yílù shang jīngguòle hěn duō dìfang.
