## What Was Built

A **complete, verified HSK knowledge system** with 10 Python files (2,700+ lines of code):

### Core Modules
1. **pdf_extractor.py** (470 lines)
   - Extracts text from HSK PDFs (Levels 1-3)
   - Preserves document structure
   - Saves as raw text + JSON

2. **content_parser.py** (400 lines)
   - Parses vocabulary entries (Chinese, pinyin, English, level, lesson)
   - Extracts grammar rules (name, explanation, examples, usage)
   - Identifies example sentences with translations
   - Outputs JSON for further processing

3. **vector_store.py** (550 lines)
   - FAISS local vector database (no external APIs)
   - Sentence-transformers for multilingual embeddings
   - Semantic search by query
   - Filtering by HSK level & content type
   - Save/load index persistence

4. **hsk_agent.py** (320 lines)
   - Claude RAG agent with conversation memory
   - Retrieves verified HSK knowledge before answering
   - Auto-citations (HSK level + source material)
   - Fallback: "Not found in HSK materials" when appropriate
   - Multi-turn conversation support

5. **pipeline.py** (450 lines)
   - Orchestrates 5-step pipeline:
     1. Extract PDFs → text files
     2. Parse → vocabulary/grammar/examples JSON
     3. Build FAISS embeddings → vector database
     4. Initialize Claude agent
     5. Prepare knowledge graph (graphify-ready)
   - CLI with `--step` and `--query` arguments
   - Full pipeline takes ~30-40 minutes first run

6. **chat.py** (280 lines)
   - Interactive CLI for multi-turn conversation
   - Shows sources for every answer
   - Statistics, history clearing, exit commands
   - Real-time feedback

## Data Flow

```
HSK PDFs (144MB each)
    ↓
Extract text + structure
    ↓ → hsk_extracted_data.json
Parse into components
    ↓ → vocabulary.json, grammar_rules.json, example_sentences.json
Generate embeddings (FAISS)
    ↓ → faiss.index + metadata.json
Claude RAG Agent
    ↓ → Query → Retrieve 5 closest matches → Synthesize with sources
```

## Customization Points

Edit **config.yaml** to:
- Change Claude model (claude-3-opus for more complex reasoning)
- Adjust similarity threshold (0.6 → 0.5 for broader search)
- Switch embedding model (paraphrase-multilingual-mpnet for better multilingual)
- Reduce batch size if memory-constrained (32 → 8)
- Enable/disable knowledge graph
- Change strictness of citations

## Support

**Error**: "No module X"
→ `pip install -r requirements.txt` again

**Error**: "ANTHROPIC_API_KEY not set"
→ `set ANTHROPIC_API_KEY=sk-ant-...` (Windows)
→ `export ANTHROPIC_API_KEY=sk-ant-...` (macOS/Linux)

**Error**: "FAISS index not found"
→ Run `python pipeline.py --step 3` to rebuild

**Performance**: Slow extraction?
→ Normal for 144MB PDFs. First run includes downloading 500MB embedding model.
